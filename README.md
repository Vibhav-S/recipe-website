# Delicious Recipes - FWD Assignment

## Folder Structure

```
/recipe-website
  index.html
  recipe1.html       (Dal Tadka)
  recipe2.html       (Aloo Sabzi)
  recipe3.html       (Steamed Rice)
  recipe4.html       (Roti / Chapati)
  recipe5.html       (Khichdi)
  about.html
  contact.html
  css/
    style.css
  images/
    hero-food.jpg      (hero banner background - any food/kitchen photo)
    dal.jpg
    sabzi.jpg
    rice.jpg
    roti.jpg
    khichdi.jpg
```

## Images
Add your own food images in the `images/` folder with the filenames listed above.
You can download free images from https://unsplash.com or https://pexels.com

## GitHub Pages Deployment
1. Create a new GitHub repository
2. Upload all files maintaining the folder structure above
3. Go to Settings > Pages > Select main branch > Save
4. Your site will be live at: https://yourusername.github.io/recipe-website
